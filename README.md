# hi, im dudeluther

i work with **wasm.rip**, and spend a lot of my time messing around with games, web tech, and reverse engineering.

i like taking games apart, figuring out how they work, and rebuilding parts of them for the browser.

a lot of what i work on involves decompiling and recompiling games, getting native code running through WebAssembly, and making things that normally wouldn't run in a browser actually work there.

i also enjoy working on older games and projects that have been forgotten a bit, and seeing what can still be done with them.

### what im interested in

game decompilation, reverse engineering, WebAssembly, browser ports, game preservation, old game engines, low-level programming, runtime systems, and web-based game technology.

### stuff i work on

i mainly work on projects involving games that need to be understood at a lower level before they can be brought to the web.

sometimes that means digging through old code, sometimes it's figuring out why something crashes, and sometimes it's rebuilding an entire part of a game so it can run in a browser.

other times, it's just seeing how far i can push something.

### wasm.rip

i'm part of **wasm.rip**, where i work on bringing games and other projects to the web.

the basic idea is taking software that wasn't designed for browsers and figuring out how to make it work there, without completely changing what made it interesting in the first place.

### currently learning

more low-level programming, better reverse engineering workflows, WebAssembly internals, game engine internals, performance optimization, and browser runtimes.

### random things i like

old software, abandoned games, weird engines, broken builds, unused code, obscure tools, messy source code, and figuring out how things work when there isn't much documentation.

i especially like finding something that looks impossible to run in a browser, then slowly figuring out what needs to change to make it work.
